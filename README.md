# CRN Technical Assessment

## Overview

This project is a RESTful Backend API developed using ASP.NET Core 8 following Clean Architecture principles.

## Technology Stack

- .NET 8
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- JWT Authentication
- FluentValidation
- Swagger
- Docker
- xUnit
- Moq

## Architecture

- Clean Architecture
- Repository Pattern
- Unit of Work
- Dependency Injection
- Middleware
- Versioning
- Logging

## Features

- JWT Authentication
- Refresh Tokens
- CRUD APIs
- Product Management
- Item Management
- Validation
- Exception Handling
- Unit Testing
- Docker Support

## Project Structure

src/
tests/
docs/

## Run

Update connection string

```
dotnet restore
dotnet ef database update
dotnet run
```
